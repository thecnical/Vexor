# Vexor Proxy — Complete Guide

The Proxy intercepts HTTP/HTTPS traffic between your browser and the target.

---

## Start Proxy

### Via CLI

```bash
# Default: 127.0.0.1:8080
vexor proxy

# Custom port
vexor proxy --port 9090

# Custom host
vexor proxy --host 0.0.0.0 --port 8080
```

### Via TUI

Press `F2` → Proxy screen → Click **▶ Start Proxy**

---

## Configure Browser

### Firefox

1. Settings → Network Settings → Manual proxy
2. HTTP Proxy: `127.0.0.1`, Port: `8080`
3. Check "Also use this proxy for HTTPS"

### Chrome / Chromium

```bash
chromium --proxy-server="http://127.0.0.1:8080"
```

### Burp-style (system proxy)

```bash
export http_proxy=http://127.0.0.1:8080
export https_proxy=http://127.0.0.1:8080
curl https://target.com
```

---

## Install CA Certificate (for HTTPS)

To intercept HTTPS traffic, install Vexor's CA certificate:

```bash
# The CA cert is generated by mitmproxy
# Location: ~/.mitmproxy/mitmproxy-ca-cert.pem

# Firefox: Settings → Privacy → Certificates → Import
# Chrome: Settings → Security → Manage Certificates → Import
# System (Kali):
sudo cp ~/.mitmproxy/mitmproxy-ca-cert.pem /usr/local/share/ca-certificates/vexor-ca.crt
sudo update-ca-certificates
```

## Proxy Screen Features

### Traffic History Table

Shows all intercepted requests:
- Method (GET/POST/PUT/DELETE)
- Host
- Path
- Status code
- Response length
- MIME type
- Timestamp

### Request/Response Viewer

Click any request to see:
- Full request headers and body
- Full response headers and body
- Highlighted JWT tokens, API keys, interesting parameters

### Send to Other Tools

Right-click or use buttons:
- **Send to Repeater** — manually modify and resend
- **Send to Intruder** — fuzz the request
- **Send to Scanner** — run vulnerability modules

### Match & Replace Rules

Automatically modify requests/responses:
- Replace headers
- Inject payloads
- Modify cookies

---

## Example Workflow

```
1. Start proxy: vexor proxy
2. Configure browser to use 127.0.0.1:8080
3. Browse target application
4. All traffic appears in F2 → Proxy screen
5. Find interesting request (login, API call, etc.)
6. Click "Send to Repeater" → modify → resend
7. Click "Send to Scanner" → run vuln modules
8. Click "Send to Intruder" → fuzz parameters
```
